# 分站客服寵物上傳教學

客服寵物是分站頁面邊緣的聯絡入口，點擊後開啟你自己的 Telegram，不影響訂單與付款。

1. 開啟 https://petdex.dev/ 挑選寵物，進入詳情頁。主站使用 Jiyi：https://petdex.dev/pets/jiyi 。
2. 點擊 **Share / 更多操作 → Download ZIP**。不用執行安裝命令，也不用安裝桌面軟體。
3. 解壓縮 ZIP，找到 `spritesheet.webp` 或 `spritesheet.png`。上傳圖片，不要上傳 ZIP 或 `pet.json`。
4. 登入主站，前往 **分站後台 → 店鋪設定 → 客服**，先設定自己的 Telegram。
5. 在「客服寵物」選擇 **Petdex 標準精靈圖**，上傳解壓後的 spritesheet 圖片。
6. 可填寵物名稱與原始 Petdex 詳情頁網址。核對預覽，滑鼠懸停可預覽揮手。
7. 點擊頁面底部 **儲存配置**，再重新整理自己的分站確認顯示及客服跳轉。

## 圖片格式

精靈圖支援 **8 欄 × 9 列**標準佈局。Jiyi 為 1536 × 1872，每格 192 × 208；第一列為待機，第四列為揮手。其他佈局請更換相容寵物，不要把整張精靈圖當作一般圖片使用。

自己的 Logo、單張角色圖片或 GIF 請選 **一般圖片 / GIF**。支援 PNG、WebP、JPG、GIF；GIF 保留自身動畫。大小及尺寸仍受站點限制。

## 恢復與排錯

- 選擇「使用預設 Jiyi」並儲存可恢復預設；選擇「隱藏客服寵物」並儲存可關閉入口。
- 未設定有效 Telegram 時不顯示寵物，不會使用主站客服。
- 顯示整張小格圖時，請改用標準精靈圖模式；佈局錯誤時確認使用 ZIP 中的原圖，而非網站截圖。
- 只上傳不會發布，必須按「儲存配置」。圖片失效可重新上傳並儲存，檔案保存在站點持久化儲存。
- 素材來源填 `https://petdex.dev/pets/寵物標識`，不要填下載連結。

Petdex 素材由使用者提交。請確認原作者授權與署名要求適用於自己的店鋪；保留來源不代表取得商業使用授權。
