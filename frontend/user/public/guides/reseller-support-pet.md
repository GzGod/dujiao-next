# 分站客服宠物上传教程

客服宠物显示在分站页面边缘，访客点击后会打开你自己的 Telegram 客服。它只改变客服入口外观，不影响订单或支付。

## 1. 到 Petdex 挑选

打开 https://petdex.dev/ ，进入喜欢的宠物详情页。例如主站使用的 Jiyi：https://petdex.dev/pets/jiyi 。详情页可以预览 Idle（待机）和 Waving（挥手）等动作。

点击详情页的 **Share / 更多操作** 按钮，在菜单中选择 **Download ZIP**。页面上的安装命令是给桌面客户端使用的，设置分站无需运行命令，也无需安装桌面软件。

## 2. 解压并找到图片

解压下载的 ZIP。以 Jiyi 为例，压缩包内包含 `pet.json` 和 `spritesheet.webp`。上传的是 **spritesheet 图片**，不是 ZIP，也不是 pet.json。

本功能支持 Petdex 标准 **8 列 × 9 行**精灵图。主站同款 Jiyi 图片为 1536 × 1872，单帧为 192 × 208。待机会播放第一行，悬停会播放第四行的挥手动作。其他布局暂不支持，不能把不匹配的整张精灵图当作普通图片上传，否则会显示所有小格。

## 3. 在分站后台上传

1. 在主站登录你的分销商账号，进入 **分站后台 → 店铺设置 → 客服**。
2. 先填写你自己的 Telegram 联系方式。
3. 在“客服宠物”选择 **Petdex 标准精灵图**。
4. 点击“上传 / 替换宠物图片”，选择解压后的 spritesheet.webp 或 spritesheet.png。
5. 可填写宠物名称和原始 Petdex 详情页地址，保留素材来源。
6. 检查预览；鼠标放上去可查看挥手动作。
7. 点击页面底部 **保存配置**。仅上传图片还不会发布到店铺。

支持的图片类型和大小仍受站点上传限制约束。图片不符合布局时会提示错误，不会替换原来已保存的宠物。

## 4. 普通图片或 GIF

如果要用自己的 Logo、角色图片或 GIF，选择 **普通图片 / GIF** 后再上传。支持 PNG、WebP、JPG、GIF，GIF 保留自身动画；普通图片不会被裁成精灵动画。

## 5. 检查上线效果

打开自己的分站域名并刷新，检查宠物、客服文案及跳转账号。没有配置有效 Telegram 客服时，宠物不会展示；不会继承主站客服。手机也能点击联系客服，并可拖动宠物位置。

选择“使用默认 Jiyi”并保存可恢复默认宠物；选择“隐藏客服宠物”并保存可关闭宠物入口。隐藏宠物不影响订单功能。

## 常见问题

- **显示整张小格图**：选错显示方式。Petdex spritesheet 请使用标准精灵图模式。
- **布局校验失败**：确认上传的是 ZIP 中的 spritesheet，且为 8 列 × 9 行；不要上传网站截图。其他布局可换一只兼容宠物，或使用单张图片 / GIF。
- **保存后没出现**：检查 Telegram 客服是否正确，确认点击了“保存配置”，再刷新自己的分站。
- **图片显示失败**：重新上传有效图片并保存。图片存于站点持久化存储，不依赖 Petdex 图片外链。
- **来源地址**：填写 `https://petdex.dev/pets/宠物标识` 形式的原始详情页，而非下载文件链接。

Petdex 上的素材由用户提交。使用前请查看原作者的授权与署名要求，确认适用于自己的店铺；保留来源不等于获得商业使用授权。
